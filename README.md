# NATALIQ на Hugo

Проект переносит дизайн и интерактивность исходного лендинга NATALIQ на Hugo. Сохранены анимированное звёздное небо, имитация Telegram-диалога, анимации появления, мобильная CTA-кнопка, FAQ и аналитические события.

## Локальный запуск

```sh
hugo server
```

## Редактирование

Главные тексты находятся в `content/_index.md`. Политика и условия — в `content/privacy.md` и `content/terms.md`. После публикации Sveltia CMS доступна по адресу `/admin/`.

CMS настроена на репозиторий `lavinfo/nataliq`.

## Публикация

GitHub Actions автоматически собирает и публикует сайт в GitHub Pages после каждого push в ветку `main`.
